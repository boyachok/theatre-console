# 0.8.2 — перенос приборов/каналов мышью

Установлен только master A0:85:E3:E2:BC:D4: новый boot/версия/роль/MAC и реально
отданный dragJS проверены. Сохранены35шагов/8приборов/публикация322, JSON перед/после
OTA совпал. STOP/LIVEoff сохранён. [Запись](DEPLOYMENTS.md).

- «По приборам»: перетаскивание за название/шапку или ручку перемещает прибор целиком,
  в том числе свёрнутый. Бросать можно на шапку или любую строку другого прибора.
- Каналы можно перетаскивать за название или ручку внутри своего прибора.
  Это только порядок строк, не перенос GPIO между контроллерами.
- Верхняя/нижняя половина цели задаёт вставку до/после; линия показывает место вставки.
- Клик по названию канала выделяет его во всех шагах, Shift — диапазон каналов,
  Cmd (macOS) / Ctrl — добавить/убрать каналы. Можно использовать и выделение ячеек.
- В «Своей партитуре» перенос выбранного канала захватывает остальные выделенные строки,
  в том числе разных приборов. Каждая строка перемещается один раз, порядок сохраняется
  именно текущий визуальный, а не порядок кликов. Перенос невыделенного канала одиночный.
- Бросок внутрь собственного выделения — без изменений. Кнопки ↑/↓ и Alt+↑/↓ остаются
  одиночным переносом. Esc/отмена native drag не переставляют строки.
- Один перенос — одна операция undo/redo, не склеивается с соседним фейдером/переключением
  режима. Повторяющиеся движения фейдера по-прежнему объединяются.
- Прежние `Device.rowOrder` и `Project.layout.order` сохраняются в JSON; новый формат
  не нужен. MAC, device/parameter/step ID, значения, тайминги, публикация и пресеты не меняются
  от перетаскивания. В LIVE нет GO/смены исполняемой сцены от выбора названия или переноса.

Также исправлена ложная ошибка Helmet/standard после перезапуска master: узел с
`protocol=0/deviceBoot=0` ещё не опознан, default `role=slave` не считается фактическим
типом. Подтверждённый неправильный тип по-прежнему отклоняется с именем/MAC в ошибке.
Отсутствующий назначенный узел по-прежнему не считается готовым для опубликованного GO.

Проверки:75 domain-тестов, TypeScript, native ASan/UBSan, production MOCK ESP browser
с настоящим mouse drag (прибор по названию, канал, Shift/Cmd группа, undo, LIVE без GO),
границы320/375/390px и SDK master build. Это не физический тест выходов.

Master обновлён по отдельному разрешению после свежего workspace/settings backup
и сервисногоSTOP; slave/helmet/PWM не обновлялись.
Постоянное отключение UART и аппаратная диагностика1/7 в эту задачу не входят.
