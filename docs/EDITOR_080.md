## Таблица и мышь

До чтения workspace из master редактирование блокируется: нельзя успеть изменить
старую локальную копию и затем потерять правку при поздней загрузке данных.

Один клик выбирает ячейку, двойной переключает уровень/бинарный запрос. Для мыши
остались Inspector и появились панель быстрой правки, текстовый ввод и фейдер уровня.
Shift+клик выбирает прямоугольник; Cmd/Ctrl+клик добавляет отдельные ячейки.
Заголовок шага выбирает столбец целиком; Shift выбирает диапазон столбцов.
Выбор диапазона сам по себе не отправляет GO. Обычный человеческий выбор шага в LIVE
сохраняет существующее поведение предпросмотра. Стрелки курсора никогда не отправляют GO.

Панель быстрой правки показывает область:
- выделенные ячейки;
- выбранный прибор в выбранном шаге;
- все приборы в выбранном шаге;
- выделенные строки во всех шагах.

Уровень меняется независимо от Fade in/out и задержки старта. Для обычного аудио
уровень — громкость, а не номер файла. У реле/голоса бинарные0/100; промежуточные
проценты пропускаются. Времена входа/выхода реле означают задержки включения/выключения,
не аналоговый fade. Параметры, которым операция не подходит, не затрагиваются.
Окно перед применением показывает охват, после — фактическое число изменённых ячеек.
Панель справа применяет совместимый параметр ко всему выделению. Общие времена
выделенных столбцов меняют только отредактированное поле, не затирая остальные времена.

## Клавиатура

- Стрелки: курсор по параметрам и шагам, без изменения значений и без навигации master.
- Shift+стрелки: диапазон; Cmd/Ctrl+клик: отдельные ячейки/столбцы.
-1…9:10…90%;0:0%;`=`:100%. V (либо Enter на ячейке): ввод уровня.
- I: Fade in / задержка включения реле; O: Fade out / задержка выключения.
- D: задержка старта света/обычного аудио. Ноль допустим.
- Enter подтверждает ввод; Esc отменяет. Время можно полностью очистить и набрать заново.
- Alt+Up/Down переставляет строку; Cmd/Ctrl+Z отменяет, Shift+Z повторяет.
- `?` / кнопка «Клавиши» открывает подсказку. I/O/V/D привязаны к физическим клавишам,
  работают независимо от латинской/русской раскладки. Чужие текстовые поля и модальные окна
  горячие клавиши не перехватывают.

Undo хранит до80 состояний с объединением быстрых движений фейдера. Меняет только draft,
не откатывает опубликованную версию master/его счётчики. Загрузка проекта очищает историю.
Крупные проекты используют структурное разделение неизменённых сцен, а не полную копию
всего спектакля при каждом движении фейдера.

## Раскладка

«По приборам»: приборы перетаскиваются целиком, строки — внутри прибора. «Своя партитура»:
без заголовков-групп, свободный порядок строк разных контроллеров; физический прибор остаётся
в подписи. Есть drag handles и мышиные ↑/↓, плюс Alt+стрелки. Порядок сохраняется в JSON.
Имена редактируются в существующем окне «Приборы». Смена представления не меняет выходы,
но может штатно синхронизировать обновлённый JSON/снимок проекта без GO.

## Время эффектов и синхронизация

Новые циклы DIM/AC/ленты: от1/15с до15с; аппаратные миллисекунды округляют1/15с до67мс.
Регулятор периода логарифмический. Fade и длительность сцены этим диапазоном НЕ ограничены.
Старые файлы с иными периодами читаются без молчаливого изменения опубликованной партитуры;
при редактировании периода применяется новый диапазон.

Существующая автоматическая синхронизация остаётся: LIVE preview в RAM, неизменённые фейды
не перезапускаются. Workspace master сохраняется отдельно с debounce; опубликованные планы
автоматически STORE/CRC/ACK записываются на исполнители. Не каждый кадр фейда пишет flash.
Текущий preview несёт полную cue512B примерно раз в200мс на контроллер, плюс ACK/служебные
пакеты; эффекты и фейды считаются локально. Хороший RSSI — не измерение загрузки эфира.
Отдельной кнопки «разовый залив» не добавляли; STOP/reconnect/удержание выходов сохранены.

## Подготовленные PWM-эксперименты — только отдельные bench-сборки

Обычная сборка не меняет8бит/25кГц. Для проверки плавности есть end-to-end дробный
внутренний fade без промежуточного8бит округления (wire-уровни по-прежнему8бит).

```
PWM_BITS=10 ./deploy build slave
PWM_BITS=12 PWM_HZ=8000 ./deploy build slave
PWM_BITS=12 PWM_HZ=8000 PWM_GRAY=0.18 ./deploy build slave
```

Выходные каталоги различаются по bits/hz/gamma/gray. Это BUILD, не прошивка.
Дополнительно PWM_GAMMA=0.5…3; gray0.05…0.95 — средняя точка кривой после gamma,
по умолчанию gamma1/gray0.5 (линейно). Gray0.18 при gamma1 даёт18% выхода на50% команды.
Низ не имеет принудительного ненулевого порога:0 строго OFF, полный уровень строго ON,
инверсия применяется один раз после кривой. Точность фейда проверена численно на настоящем
Runner+mock hardware: >800 разных запрограммированных уровней за1с против256 у8бит.
В `/api/status` обычного исполнителя есть `pwmBits`, `pwmHzConfigured`, `pwmGamma`, `pwmGray`.
`pwmHz` — SDK readback, который при duty0 может быть0. На новой частоте возможны ограничения
силового драйвера, акустический шум и отличия фактической частоты; это НЕ измерение осциллографом.
Нужен отдельный согласованный тест одной платы. Битность адресной WS2811 этим не меняется.
