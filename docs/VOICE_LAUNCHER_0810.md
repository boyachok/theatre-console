# 0.8.10 — стартовое окно голоса шлема

**Подготовка интерфейса; master не прошит.** Установленные версии не менялись:
master 0.8.8, №6 — 0.8.9/AC082, остальные — 0.8.7 (по последним проверкам).
Связи с реальными контроллерами, STOP/GO, OTA и испытаний выходов в этой работе нет.

## Интерфейс

- Каждая загрузка страницы начинает с компактного окна: **«Голос шлема»** и
  выпадающий список имён пресетов. Выбор явно применяет независимый звук сразу,
  в том числе при заблокированной партитуре. Само открытие окна ничего не выбирает.
- Внизу справа **⋯**: **«Редактирование звука»**, **«Редактирование партитуры»**.
- Звук открывает существующий редактор: EQ, разборчивость, алгоритм и параметры,
  сохранение/создание/переименование/удаление обычных пресетов. Закрытие возвращает
  компактное окно; несохранённые настройки остаются в `working` как раньше.
- **EQ сохраняется отдельно в каждом пресете**, вместе с параметрами эффекта,
  фильтрами и разборчивостью. Для замены сохранённых настроек — «Сохранить пресет»;
  для отдельного варианта — «Сохранить как новый». При замене несохранённого `working`
  выбором другого пресета остаётся существующее подтверждение.
- Партитура: собственный диалог **«Вы точно хотите редактировать партитуру?»**,
  кнопки **«Нет» / «Да»**. «Нет»/Escape оставляет компактное окно. «Да» показывает
  партитуру **заблокированной**. Доступ к редактированию — отдельное нажатие замка.
- Разблокированный master в другом браузере не означает согласия этого окна на
  редактирование. Согласие локально для текущей страницы, не сохраняется при reload;
  при входе в партитуру включается общий замок, если master сейчас разблокирован.
- Кнопка **«Голос шлема»** в шапке партитуры возвращает стартовое окно и блокирует
  редактирование. Она не останавливает спектакль и не переключает сцену/LIVE.
- Нет назначенного шлема: список отключён с пояснением, звук недоступен, но можно
  подтвердить вход в партитуру и отдельно открыть замок для настройки устройств.
  При нескольких назначенных шлемах показан отдельный список с именем каждого;
  редактор звука относится к последнему выбранному/сфокусированному шлему.

## Что не изменено

Нет нового формата партитуры/банка, миграции, аппаратных настроек или команд сцен.
Используется существующий независимый банк по MAC и существующий sound API.
Переходы не публикуют партитуру, не отправляют GO/STOP/LIVE и не меняют текущий RUN.
Нормальный однократный автозапуск первой сцены **при загрузке master** остаётся
по контракту 0.8.5; открытие страницы его не инициирует и не переигрывает.
Блокировка/разблокировка не переармирует этот запуск. Общая версия исходников
0.8.10 не требует перепрошивать шлем, пульт и ведомые ради нового интерфейса.

## Проверки и будущая установка

TypeScript, 95 domain-тестов, production MOCK ESP UI и локальный UI (100×170 ячеек),
native ASan/UBSan и прежние browser-проверки. Новый browser-сценарий проверяет:
отсутствие партитуры под стартовым окном, «Нет», «Да» + отдельный замок,
внешнюю разблокировку, reload, сохранение EQ/эффекта в одном пресете без изменения
другого, создание/удаление пресета, отсутствие записей партитуры и смены runtime.
Размеры окна: 320/375/390, низкий desktop и landscape; меню — клавиши/мышь/Escape.
Это проверки ПО на моках, не физического звука/выходов. Master SDK-сборка прошла
(ESP32 core 3.3.11, ESP32-S3/16 MB); SDK-образы других ролей не собирались.
Никакие устройства не прошивались.

Подготовленный app-only образ:
`build/console-master-wifi/console.ino.bin` — **1 320 256 байт**,
SHA-256 `608e57f56b9c76ede0d788034a5e9b8964bea0c37bc0da4919ee6df23e018d7b`.
Только master; имя каталога сборки само по себе не подтверждает этот SHA при
будущих пересборках. Копия: `~/Desktop/YOUR_WIFI_SSID/Firmware_0.8.10_master_voice_NOT_FLASHED/`.

Сборка будущего master: `AC_PROFILE=current ./deploy build master` — **только сборка**.
До отдельно разрешённой установки заново получить текущие MAC/роль/master boot,
свежие партитуру/банки/working и точный SHA образа. Учесть авторизованный автозапуск
master после reboot; не использовать исторические копии поверх новых правок.
Бинарник приложения не является резервной копией актуальных NVS/FS/полной flash.
