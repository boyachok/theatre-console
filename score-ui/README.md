# Консоль — интерфейс 0.3.0

React/TypeScript. Два явных режима: локальный макет и сборка для мастера ESP0.7.
Подготовка прошивки/пинов/первого испытания: [../CONSOLE.md](../CONSOLE.md).

## Запуск

```sh
npm install
npm run dev
```

http://localhost:5173 — **локальный режим**, не отправляет запросов к ESP и не
выдумывает телеметрию. Телефон использует IP ноутбука в той же LAN.

```sh
# Разработка с настоящим мастером, только после его обновления до 0.7:
CONSOLE_TARGET=http://192.168.50.119 VITE_CONSOLE_BACKEND=1 npm run dev
# Production для включения в образ мастера (автоматически делает ./deploy):
VITE_CONSOLE_BACKEND=1 npm run build
```

В режиме ESP запросы относительные `/api/console/*`; без флага нет связи с ESP.
Нет внешних CDN/шрифтов. Для curl на этом Mac использовать `--noproxy '*'`.

## Редактирование

- Шаги1,2,3… горизонтально; приборы и параметры вертикально, закреплённые заголовки.
- Стрелка прибора сворачивает его строки без потери данных. Общая таблица галочек
  модулей:8DIM,2REL,SPI,SOU; от1 до10 приборов, названия и цвета параметров.
- Клик по нулевому диммеру ставит целевое100%, затем доступна регулировка. Это
  редактирование, **не немедленное включение физического выхода**.
- Линейные fade-in/out, общие времена и переопределения; единица — секунды,
  числовой инкремент **0.2с**. Пустое время наследует общее значение.
- Копия целого шага вставляется после выбранного; переносы сохраняют содержимое/ID.
- Исполнение — отдельный плеер в шапке. Короткие кнопки: шаг; удержание3с:
  первый/последний. Уже текущий изменённый шаг можно применить явно повторно.
- Та же композиция вперёд продолжается без повтора после EOF, назад — заново,
  пустой файл — fade-out/STOP. В локальном режиме настоящий аудиофайл не звучит.
- Эффекты ленты wave/fill/static остаются в редакторе. Реальная командаplay для
  ленты пока отклоняется: модель DATA/DATA+CLOCK и подключение не подтверждены.

## ESP-режим

В «Сети» реальные IP, измерения и подтверждения, кнопки идентификации и сброса
реестра. В «Приборах» назначается **MAC контроллера**, не изменяемый вручную IP.
Для включения реле нужно выбрать активный HIGH/LOW. Старые0.4/0.6 обнаруживаются,
но компилятор не разрешает им выдавать партитуру как новой прошивке0.7.

Веб-плеер посылает явно выбранный шаг черновика, физические кнопки мастера используют
опубликованную неизменяемую версию. На ведомом собственные линейные фейды/задержки;
повторы пакетов не перезапускают сцену. Подтверждение — приём/знание сцены, не датчик
нагрузки. Сетевой тест выключает дополнительные пробы, не сценовый heartbeat.
RTT/счётчики теста не смешиваются со счётчиками пакетов сцен.

## Хранение

Локально: localStorage и JSON. На ESP: загрузка workspace с мастера при открытии,
автосохранение с задержкой1.5с и браузерный резерв; публикация сохраняет версию на
мастере и передаёт части ведомым с CRC. Таблица сети показывает загруженную версию.
Номер версии не является обещанием доставки всем. Ошибка записи не показывается
как успешное сохранение. Совместного редактирования/слияния двух браузеров пока нет.

`schemaVersion=1`, интерфейс0.3.0, прошивка0.7.0 — разные версии. JSON0.1/0.2
совместим; новые необязательные поля — MAC и полярность реле. Fingerprint FNV-1a
служит контролю целостности, не криптографической подписью.

## Код и проверки

`domain/compile.ts` — проверка привязок и компиляция абсолютных выходов/миллисекунд;
`transport/esp.ts` — настоящий HTTP-клиент; `transport/network.ts` — контракт и
честный disconnected-адаптер; компоненты ячеек не выполняют сетевые команды.

```sh
npm test
npm run build
VITE_CONSOLE_BACKEND=1 npm run build
PLAYWRIGHT_PATH=/Users/boyacheek/.npm/_npx/e41f203b7505f1fb/node_modules/playwright npm run test:esp-ui # MOCK HTTP master
PLAYWRIGHT_PATH=/Users/boyacheek/.npm/_npx/e41f203b7505f1fb/node_modules/playwright npm run test:ui
```

Проверяются100×120 ячеек,320/375/390px, сворачивание, клик100%, инкремент0.2,
независимость редактирования/исполнения, копирование/перенос, удержания, CRUD,
статические эффекты, версии/JSON, честная пустая сеть и контракт настоящего API.
Веб-тесты не подтверждают работоспособность ещё не прошитых физических плат.
