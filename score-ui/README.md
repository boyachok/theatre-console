# Theatre console — исходники 0.8.11

Компактный операторский UI: карточки контроллеров4×4, сеть RTT/RSSI/LED,
без отладочных сведений, графиков, быстрой панели и клавиш правки.
Старт: «Голос шлема»/пресеты, меню ⋯ для полного звука/EQ и партитуры.
Подтверждение входа не снимает замок: нужен отдельный клик.
Shift/Cmd/Ctrl-выделение, стрелки безGO, Inspector и перетаскивание сохранены.
Один клик выбирает, двойной переключает. «Вид сортировки» / «По приборам».
[Текущий контракт](../docs/OPERATOR_UI_0811.md). 26.11 интерфейс0.8.11 установлен
на основной master; текущие партитура, банки и working сохранены байт-в-байт.
Резервный master BFA8 пока0.8.10, остальные роли ради UI не обновлялись.
[Проверенная запись](../docs/DEPLOYMENTS.md).

React/TypeScript/Vite. Версия общая с master/slave/remote и берётся из `../version.json`.
[Прошивка и первый стенд](../CONSOLE.md) · [Пинаут](../docs/PINOUT.md).

```sh
npm ci
npm run dev
```

http://localhost:5173 — локальный редактор, **без соединения с ESP**. Телефон
использует адрес ноутбука в той же LAN. Нет внешних CDN/шрифтов и выдуманной телеметрии.

```sh
CONSOLE_TARGET=http://192.168.50.119 VITE_CONSOLE_BACKEND=1 npm run dev
VITE_CONSOLE_BACKEND=1 npm run build
```

В режиме ESP запросы относительные `/api/console/*`; требуется та же версия мастера.
При `./deploy` ESP-build автоматически включается в прошивку. Никакой отдельной записи
файловой системы для веба не требуется. `curl` локальных адресов: `--noproxy '*'`.

## Редактор

- Светлая контрастная тема, горизонтальные шаги1,2,3… и сворачиваемые группы приборов.
- До10 приборов:12 физических DIM (в настройках1–8),2REL,WS2811,аудио иAC220.
  Скрытые модули сохраняют данные.
- Один клик выделяет. Двойной клик диммера переключает100%/0, аудио — выбранный
  файл (первый1)/пустойSTOP; последнее выбранное число запоминается. Уровень/номер файла
  меняются в правой панели, на телефоне —в окне параметров. Реле также toggle.
- Без LIVE редактирование не запускает выходы: исполнение отдельно плеером в шапке.
  В «Предпросмотре» изменения работающей сцены применяются в реальном времени.
- Линейные времена в секундах, инкремент0.2с. Пустое индивидуальное время наследует
  общее время шага. Полная копия/перенос шага сохраняет значения/времена/стабильныеID.
- Короткие кнопки плеера:шаг; удержание3с:первый/последний. Текущий изменённый шаг
  можно применить явно повторно. Новая сцена прерываетfade с достигнутого уровня.
- WS2811:wave/fill/static,RGB/GRB,800/400кГц,до1024 управляемых точек. Приhold
  компилятор восстанавливает предшествующую авторскую программу; одинаковая программа
  вперёд сохраняет фазу, назад/при восстановлении перезапускается.
- Звук вперёд с тем же файлом продолжается и не повторяется послеEOF; назад —заново.
  Локальный редактор не воспроизводит настоящиеMP3 сSD плеера.

Удаление шага использует собственный диалог с галочкой «Не спрашивать до перезагрузки
страницы». Решение хранится только в памяти вкладки; после reload спрашивает вновь.
Импорт и удаление приборов тоже не зависят от браузерного `window.confirm`.

## ESP и данные

MAC-привязка, тип, имя и каналовые поля собраны в «Приборах». Для включённого реле
требуется явнаяHIGH/LOW полярность. DIM9–12 и аппаратные настройки WS2811/PWM/AC
скрыты без удаления данных. «Сеть» показывает реальные RTT/RSSI/оценку связи,
есть отдельное явное «Мигать»; графики/тест/сброс и диагностические таблицы убраны.
Пульт виден в сети, но не предлагается в назначениях приборов. Неизвестные значения
остаются «—», а устаревшие узлы не показываются зелёными.

Локально:localStorage/JSON. НаESP:workspace мастера, autosave1.5с и браузерный резерв;
публикация сохраняет неизменяемую версию и рассылает части поMAC/CRC. УспехHTTP
публикации не выдаётся за доставку всем. Веб-плеер проверяет черновик, физические
кнопки используют опубликованный план. Совместное редактирование не реализовано.

JSON schema1 сохранена. Старые файлы с8диммерами принимаются: в черновик добавляются
4выключенных модуля, опубликованный снимок/fingerprint не переписывается.
FNV-1a —контроль целостности, не криптографическая подпись. На мастере workspace
сжимается для надёжных повторных записей100×10, но API/экспорт остаются обычнымJSON.
