# Версии интерфейса

## 0.3.0 — Консоль, инкремент0.2с и тестовая связь с ESP

- Заголовок «Консоль», длиннее поле спектакля; приборы сворачиваются стрелками.
- Клик по нулевому диммеру ставит100% в черновике; ручная регулировка остаётся.
- Единицы времени подтверждены: секунды, инкремент0.2, старые значения не пересчитываются.
- ESP-режим собирается отдельным флагом, включается в мастер0.7; обычный dev остаётся локальным.
- MAC-привязка прибора, реальные IP, выбор активного HIGH/LOW реле.
- Реальное хранение workspace/публикации, API запуска черновика, подтверждения шагов/версий.
- В «Сети» идентификация каждого контроллера/мастера и сброс реестра; тестовые метрики не смешиваются со сценовыми.
- Нет фиктивных измерений; производственное включение ленты заблокировано до уточнения модели.
- Тесты интерфейса/домена и обе сборки проверяются отдельно; физический стенд ещё требуется.

## 0.2.0 — горизонтальные шаги и общая настройка приборов

- Приборы/параметры вертикально, шаги числовыми столбцами слева направо.
- Плеер и дублирование-иконка в шапке, нижняя панель и поясняющие подписи удалены.
- Перестановка столбцов перетаскиванием или кнопками влево/вправо.
- Общая таблица галочек DIM1–8/REL1–2/SPI/SOU1, имена, цвета и readonly IP.
- Добавление/удаление приборов обновляет весь черновик, сохраняя другие данные и опубликованную версию.
- Панель сети: RTT/RSSI-графики, счётчики TX/RX/ACK/потерь, подтверждённый шаг и переключатель теста.
- Сетевой адаптер пока disconnected: никаких реальных RF-пакетов и фиктивных измерений.
- Статический эффект ленты: цвет и яркость; без ненужных параметров движения.
- Совместимость с JSON0.1.0, текущая версия записывается при экспорте/сохранении.
- Шаг/единица фейда ожидают уточнения «0.5с или0.5мс», не заменялись предположением.
- Модульные/браузерные тесты, 100×120 ячеек и мобильные размеры пройдены.

## 0.1.0 — первый согласовательный макет

- React + TypeScript + Vite, полностью локальные ресурсы, адаптивная матрица.
- Один начальный шаг, десять универсальных приборов, 8 PWM / 2 реле / звук / лента.
- Полное дублирование шага, перенос строк, удаление с сохранением минимум одного шага.
- Независимые редактор и плеер шагов; удержание назад/вперёд 3с вызывает первый/последний.
- Проценты, раздельные линейные fade-in/out, задержки ON/OFF реле, общие времена и переопределения.
- Продолжение одинакового трека вперёд, перезапуск назад, пустой трек с fade-out.
- Названия и цвета параметров, скрытие неиспользуемых модулей без удаления данных.
- Генератор волны/заполнения и локальный визуальный предпросмотр.
- Автосохранение браузера, JSON-бэкап, отдельная неизменяемая опубликованная версия.
- Модель переходов с дедупликацией и отдельная транспортная граница; реальной связи с ESP нет.
- Модульные и браузерные проверки, в том числе 100×120 ячеек и узкие экраны.
