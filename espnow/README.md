# Архив управления 0.3.1 ESP-NOW

Сохранён перед переходом на Wi-Fi LAN 0.4.0. По умолчанию deploy больше не использует
этот каталог. Для отдельного сравнения/отката обеих ролей:

```sh
PROFILE=espnow ./deploy master
PROFILE=espnow ./deploy slave
```

Фиксированный канал 6, собственная AP мастера Stage-Master-XXXXXX/debug123,
веб 192.168.4.1, прежние GPIO и NVS. С текущим Wi-Fi-профилем не взаимодействует.
Новый основной профиль: ../control/, инструкция ../WIFI.md.
